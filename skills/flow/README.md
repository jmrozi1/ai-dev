# Flow skills

Skills in this category explain how to use the Flow workflow and commands correctly.

Put skills here when they are about things like:

- `flow-*` command usage
- workflow lifecycle and checkpoints
- branch and repository safety
- Flow state, diffs, promotion, blocking, or completion

Keep planning, review judgment, testing strategy, and ChatGPT-specific orchestration in their own categories.

Each skill should live in its own subdirectory with a `SKILL.md` file.
